# Vector QR 0.1 — генератор QR-кодов для Figma

**Офлайн-генератор векторных QR-кодов**. Создавайте редактируемые QR-коды на холсте Figma, экспортируйте SVG или PNG с прозрачным фоном.

> **Статус:** открытый исходный код версии 0.1. Плагин пока не опубликован в Figma Community, устанавливается через Development Plugins.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP** или клонируйте его.
2. Сохраните `manifest.json`, `code.js` и `ui.html` в одной папке.
3. В **Figma Desktop** откройте **Plugins → Development → Import plugin from manifest**.
4. Выберите `manifest.json`.
5. Запустите **QR генератор — Vector QR 0.1** из раздела Development.

После изменений в GitHub нужно обновить локальные файлы и перезапустить плагин. Прямого подключения Development Plugin по URL GitHub нет.

## Возможности

- URL, текст, Wi-Fi, SMS, телефон и email.
- Цвет QR и фона, переключатель **«Без фона»**.
- SVG-логотип с перекраской в цвет QR или прямоугольное отверстие под логотип.
- PNG 1000 × 1000 px, прозрачный или с выбранной заливкой.
- SVG с сохранением векторной структуры.
- При добавлении на холст QR и фон — **разные слои**; фон можно скрыть или удалить позже.
- RU/EN. Вёрстка по согласованному макету Figma без прокрутки; на маленьких экранах уменьшается масштаб.

## Проверка качества

В репозитории есть автоматическая статическая проверка исходников:

```bash
node scripts/validate.mjs
```

Тесты в браузере и на имитации Figma API ранее проходили. Это не гарантирует полную совместимость со всеми версиями Figma Desktop. Перед публичной публикацией в Community нужно выполнить тестирование внутри Figma и пройти проверку Figma.

## Конфиденциальность и лицензии
