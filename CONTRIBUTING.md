# Contributing

Thanks for contributing to QR generator.

1. Open an issue before a significant feature change. Please preserve the approved UI proportions, avoid extra design elements and retain offline generation.
2. Keep changes focused; include manual Figma reproduction steps for interface or SVG issues.
3. Run `node scripts/validate.mjs` and test the plugin in Figma Desktop before proposing a release.
4. Preserve third-party copyright and license notices. By submitting contributions, you represent that you have the rights needed to contribute and agree that your original contributions are licensed under MIT, except where clearly stated otherwise.
5. Never submit private customer documents, QR payloads, login tokens or Wi-Fi passwords.

Report security concerns privately to the maintainer rather than sharing exploitable payloads in public issues. The maintainer should configure a private security reporting channel before broad distribution.
