# Public release checklist

## Repository
- [x] Keep the final Figma plugin source unchanged.
- [x] Preserve the vendor MIT attribution and include Apache 2.0 notice for qrcode-terminal adaptation.
- [x] Add an MIT license for original contributions (subject to contributor rights).
- [x] Add DENSO WAVE trademark notice, privacy policy, and GitHub support link.
- [x] Verify no private `.fig`, credentials or personal data appear in the uploaded files.
- [x] Add static validation via GitHub Actions.
- [ ] Create and verify `kbnndk/vector-qr` as a public GitHub repository.
- [ ] Push the prepared files to `main` and confirm the Actions workflow succeeds.

## Figma Community (separate process)
- [ ] Confirm all Figma assets in this project may be publicly distributed.
- [ ] Run final manual tests in Figma Desktop (including logo/recolor, insertion, transparency, resizing and mobile/small windows).
- [ ] Add a verified support/privacy contact suitable for the intended audience and jurisdictions.
- [ ] Prepare original icon, screenshots, accurate listing copy and security disclosure.
- [ ] Review Figma Developer Terms and Community guidelines, then submit for review.

Source availability on GitHub does not publish the plugin in Figma Community. This checklist is a preparation aid, not legal advice.
